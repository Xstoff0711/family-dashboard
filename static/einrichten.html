🏡 Dashboard einrichten

Damit das Dashboard sicher läuft und Benachrichtigungen schicken kann, muss dieses Gerät dem Zertifikat deines Heimservers vertrauen. Das ist einmalig pro Gerät.

Prüfe die sichere Verbindung …
Zum Dashboard
Zertifikat laden

So geht's

  1. Diese Seite in Safari öffnen (nicht in Chrome) und oben auf Zertifikat laden tippen, dann Erlauben.
  2. Einstellungen öffnen. Oben steht Profil geladen. Antippen, Installieren und den Gerätecode eingeben. (Falls nicht: Allgemein → VPN und Geräteverwaltung.)
  3. Wichtig: Einstellungen → Allgemein → Info → Zertifikatsvertrauenseinstellungen und den Schalter bei Caddy Local Authority einschalten.
  4. Zurück zu dieser Seite und Erneut prüfen.
  5. Für Benachrichtigungen: Dashboard öffnen, unten auf Teilen → Zum Home-Bildschirm. Ab jetzt immer über das neue Symbol öffnen und im Profil unter 🔔 einschalten.
  1. Oben auf Zertifikat laden tippen. Die Datei landet in Downloads.
  2. Einstellungen öffnen und oben nach Zertifikat suchen. Wähle CA-Zertifikat (oft unter Sicherheit → Weitere Sicherheitseinstellungen → Verschlüsselung & Anmeldedaten → Zertifikat installieren).
  3. Die Warnung mit Trotzdem installieren bestätigen und die Datei caddy-root.crt auswählen.
  4. Chrome ganz schließen, wieder öffnen und hier Erneut prüfen.
  5. Dann im Dashboard unter Profil → 🔔 die Benachrichtigungen einschalten.
  1. Zertifikat laden und die Datei doppelklicken → Zertifikat installieren.
  2. Aktueller Benutzer → Alle Zertifikate in folgendem Speicher speichern → Vertrauenswürdige Stammzertifizierungsstellen → Fertig stellen und die Sicherheitsfrage mit Ja beantworten.
  3. Browser neu starten und Erneut prüfen. Firefox: Einstellungen → Datenschutz & Sicherheit → Zertifikate anzeigen → Zertifizierungsstellen → Importieren.
  1. Zertifikat laden und die Datei doppelklicken. Sie öffnet sich in der Schlüsselbundverwaltung (Schlüsselbund „Anmeldung“ oder „System“).
  2. Das Zertifikat Caddy Local Authority doppelklicken → Vertrauen → Bei Verwendung dieses Zertifikats: Immer vertrauen.
  3. Fenster schließen, Passwort eingeben, Browser neu starten und Erneut prüfen.
  1. Zertifikat laden.
  2. Arch/CachyOS/Fedora: sudo trust anchor --store ~/Downloads/caddy-root.crt
    Debian/Ubuntu: Datei nach /usr/local/share/ca-certificates/ kopieren, dann sudo update-ca-certificates.
  3. Chrome und Firefox nutzen teils eigene Speicher: dort unter Einstellungen → Zertifikate → Zertifizierungsstellen importieren.
  4. Browser neu starten und Erneut prüfen.

Das Zertifikat stammt von deinem Heimserver. Installiere es nur im eigenen Netz oder über Tailscale und gib die Datei nur an Familienmitglieder weiter.
